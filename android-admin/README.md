# EWA Teacher Admin Android App v0.5.7

Android admin client for the EWA WordPress backend.

## Included
- Persistent secure teacher/admin session
- Dashboard and analytics
- Students and memberships
- Approve / Reject / Suspend membership actions
- Payment-proof opening
- Courses and orders
- Fee & account settings
- Notifications
- WhatsApp queue with paginated fetching
- WhatsApp Business pre-filled message handoff
- Colorful glass-style UI

## Build
Use the included GitHub Actions workflow or Android Studio with JDK 17 and Android SDK 35.
